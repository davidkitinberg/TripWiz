# TripWiz — Folder 03: How the Parts Connect

**Team:** TripWiz — Ariel University · David Kitinberg, Amit Bitton, Sagi Hassid

---

## Users

- **Users → Authentication:** sign up and sign in through Cognito.
- **Users → Frontend:** open the React app in the browser (local dev today; S3 + CloudFront planned).
- **Users → Notifications:** receive emails sent by SES (alerts and reminders).

## Frontend ↔ Backend

- **Frontend → Authentication:** the app calls Cognito directly for login; no API Gateway on auth.
- **Frontend → API Gateway REST (HTTPS):** all trip, admin, place-search, and settings calls.
- **Frontend → API Gateway WebSocket (WSS):** real-time collaboration on a trip (join, edit, cursor).

## Authentication ↔ APIs

- **Cognito → REST API Gateway:** JWT from sign-in is sent on REST requests; the built-in Cognito authorizer validates it before Lambda runs.
- **Cognito → WebSocket Authorizer:** access token is passed as `?token=` on connect; the authorizer Lambda checks it before the WebSocket handler accepts the connection.
- **Cognito → SES (dashed):** verification emails for new accounts.

## API Gateway ↔ Lambdas

- **REST API Gateway → TripWiz-Trips Lambda:** every HTTP route (trips, admin, places, optimize, etc.).
- **WebSocket API Gateway → WebSocket Handler Lambda:** connect, disconnect, join, leave, edit, cursor messages.
- **WebSocket API Gateway → WebSocket Authorizer Lambda:** only on `$connect`.

## Lambdas ↔ Data

- **TripWiz-Trips, WebSocket Handler, TripWiz-Validate, TripReminder → DynamoDB:** read and write trips, users, alerts, connections, and settings.
- **TripWiz-Trips → Secrets Manager:** optional API keys at runtime.

## Lambdas ↔ External services

- **TripWiz-Trips → Amazon Bedrock:** AI route optimization.
- **TripWiz-Trips → AWS Location:** place search and route calculation.
- **TripWiz-Validate → Open-Meteo:** weather forecasts for trip stops.

## Scheduling ↔ Lambdas

- **EventBridge → TripWiz-Validate:** nightly weather check.
- **EventBridge → TripReminder:** daily reminder job (8:00 UTC).

## Notifications chain

- **TripWiz-Validate → SNS:** publishes weather alerts.
- **SNS → SnsToSes Lambda:** alert payload delivered as an SNS event.
- **SnsToSes Lambda → SES:** formatted alert emails.
- **TripReminder Lambda → SES:** trip reminder emails (direct, no SNS).

## Monitoring

- **All Lambdas → CloudWatch:** logs and metrics.
- **CloudFormation SAM:** deploys and wires the stack; not a runtime data path.
